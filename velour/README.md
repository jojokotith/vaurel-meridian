# VELOUR — демо-сайт лаунж-бара

Статический сайт без сборки и зависимостей: HTML + CSS + JavaScript.

## Запуск
```bash
cd lounge
python3 -m http.server 8080
```
Откройте http://localhost:8080. Подойдёт любой статический хостинг (Netlify, GitHub Pages, nginx) — достаточно залить папку целиком.

## Где что менять
- `js/config.js` — название, подпись, телефон, адрес, график работы, валюта, **все позиции меню, цены, опции**, флаг `demo`.
- `assets/menu/*.svg` — иллюстрации-заглушки. Замените на фото (jpg/webp, 4:3) и укажите путь в поле `image` позиции.
  Если файл не найдётся, автоматически покажется `placeholder.svg`.
- `css/styles.css`, блок `:root` — цвета и шрифты.
- `index.html` — тексты разделов «О нас», «Как это работает», первый экран, иллюстрация зала (SVG в `.hero__art`).
- `js/intro.js` — тайминги заставки (функция `play`).

## Демонстрационный режим
- Заявка не отправляется на сервер, оплата не подключена, имя/телефон нигде не сохраняются.
- Доставка — только пример (позиции 18+ с доставкой оформить нельзя).
- В localStorage хранится только состав корзины. Заставка показывается при каждом заходе (скорость — объект `TIMING` в `js/intro.js`).
- Чтобы подключить реальную отправку, замените тело функции `finishOrder()` в `js/app.js` на запрос к вашему API / боту.
