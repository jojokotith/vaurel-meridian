# VAUREL · Meridian

An interactive 3D concept watch site: take the watch apart, turn it over, look at the movement through the caseback, then configure model, case, dial and strap.

**Live:** https://jojokotith.github.io/vaurel-meridian/

## Features
- Real-time 3D watch (three.js), three models: Meridian, Carré, Abyss
- Scroll-driven story: case, exploded anatomy, movement, specifications
- Configurator synced with the 3D model; free 3D view (drag, pinch, keyboard)
- Bag with quantities, saved in the browser; demo checkout summary
- Responsive from 360 px phones to 4K, mobile menu, no-WebGL fallback

## Tech
Single `index.html`: three.js 0.165, GSAP 3.12 + ScrollTrigger, Lenis. No build step.

## Note
VAUREL is a fictional brand. Watches, prices and specifications are a design concept, not products for sale. Checkout and payment are not connected.
