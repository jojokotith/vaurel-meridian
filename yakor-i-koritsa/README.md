# «Якорь и корица» — демо-сайт кофейни у старой гавани

Статический сайт без сборки: HTML + CSS + JavaScript. Фотографии — настоящие снимки с Unsplash,
сохранённые локально в `assets/photos/` (источники — в `ATTRIBUTION.md` и в комментариях рядом с фото).

## Запуск
```bash
cd anchor-cinnamon
python3 -m http.server 8097
```
Откройте http://localhost:8097. Для хостинга загрузите папку целиком.
Заставка показывается при первом заходе; повторить — «Показать заставку» в подвале.

## Где что менять
- `js/data.js` — название и подпись, адрес, телефон, ссылки на соцсети (`socials[].url`), часы работы,
  всё меню и цены, витрина дня, галерея (подписи, группы, alt-тексты, файлы фото).
- `assets/photos/` — фотографии. Фото заставки, первого экрана и истории подключены в `index.html`
  (рядом указан источник), остальные — в `js/data.js`. Не забудьте обновить `ATTRIBUTION.md`.
- `css/styles.css`, блок `:root` — цвета и шрифты. Фирменный якорь — `<symbol id="anchor">` в начале `index.html`.

## Демо-режим
- Корзина, пересчёт суммы и проверка формы работают, но заказ **никуда не отправляется**: после «отправки»
  форма и корзина очищаются. Для реального приёма заказов замените `setTimeout(done…)` в `js/main.js`.
- Оплата и доставка не подключены. В браузере хранится только состав корзины и отметка о просмотренной заставке.
- Кнопки соцсетей показывают подсказку, пока в `js/data.js` не указаны настоящие адреса. Карта — схема-иллюстрация.
