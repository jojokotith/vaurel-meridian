# «Солёный свет» — демо-сайт ресторана у моря

Статический сайт без сборки: HTML + CSS + JavaScript. Иллюстрации — локальные SVG.

## Запуск
```bash
cd restaurant
python3 -m http.server 8090
```
Откройте http://localhost:8090. Для хостинга достаточно загрузить папку целиком.
`dist/solyony-svet.html` — тот же сайт в одном файле (открывается двойным кликом).

## Где что менять
- `js/data.js` — название и подпись, телефон, адрес, ссылки на карты и соцсети (`links[].url`),
  график работы, правила брони (макс. гостей, шаг времени), **всё меню и цены**, сцены галереи с подписями и описаниями фото.
- `assets/img/` — иллюстрации. Замените на фото (jpg/webp) и поправьте пути в `js/data.js`
  (меню и галерея) и в `index.html` (фото в разделе «История»). Не забудьте обновить описания `alt`.
- Панорама первого экрана нарисована прямо в `index.html` (блок `<svg class="panorama">`):
  её можно заменить на `<img>` с фото, убрав анимацию луча.
- `css/styles.css`, блок `:root` — цвета и шрифты.

## Демо-режим
- Форма бронирования проверяет поля, показывает загрузку и подтверждение, но **ничего не отправляет и не сохраняет**.
  Чтобы подключить реальную бронь, замените `setTimeout(showSuccess…)` в `js/main.js` на запрос к вашему сервису.
- Свободные столики не проверяются — показывается любое время в часы работы.
- Кнопки карт и соцсетей показывают подсказку, пока в `js/data.js` не указаны настоящие адреса.
