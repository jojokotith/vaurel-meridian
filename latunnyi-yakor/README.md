# «Латунный якорь» — демо-сайт кофейни у старого порта

Статический сайт без сборки: HTML + CSS + JavaScript. Фотографии — настоящие снимки с Unsplash,
сохранённые локально в `assets/photos/` (источники — в `ATTRIBUTION.md`).

## Запуск
```bash
cd cafe
python3 -m http.server 8095
```
Откройте http://localhost:8095. Для хостинга загрузите папку целиком.
Заставка показывается один раз; повторить — кнопка «Показать заставку» в подвале.

## Где что менять
- `js/data.js` — название и подпись, адрес, телефон, ссылки на соцсети (`socials[].url`), часы работы,
  всё меню с ценами, витрина дня и галерея (подписи, alt-тексты, файлы фото).
- `assets/photos/` — фотографии. Положите свои файлы и поправьте имена в `js/data.js`;
  фото первого экрана, истории и контактов — в `index.html` (рядом указаны источники). Обновите `ATTRIBUTION.md`.
- `css/styles.css`, блок `:root` — цвета и шрифты. Знак-якорь — `<symbol id="anchor">` в начале `index.html`.

## Демо-режим
- Корзина, пересчёт суммы и проверка формы работают, но заказ **никуда не отправляется**: после «отправки»
  форма и корзина очищаются. Чтобы подключить реальный приём заказов, замените `setTimeout(done…)` в `js/app.js`.
- Оплата и доставка не подключены. В браузере хранится только состав корзины и отметка о просмотре заставки.
- Кнопки соцсетей показывают подсказку, пока в `js/data.js` не указаны настоящие адреса.
