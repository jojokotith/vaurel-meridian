# Источники фотографий

Все фотографии — настоящие снимки с **Unsplash** (https://unsplash.com). Они распространяются по
[Unsplash License](https://unsplash.com/license): их можно бесплатно использовать в коммерческих
и некоммерческих проектах без обязательного указания автора. Нельзя продавать сами фотографии
без доработки и собирать из них конкурирующий фотосток.

Снимки скачаны с CDN Unsplash (`images.unsplash.com`) и лежат локально в `assets/photos/`, поэтому
сайт не зависит от внешних ссылок. Идентификатор каждого снимка указан ниже: исходник открывается
по адресу `https://images.unsplash.com/photo-<идентификатор>`.

Имена авторов в этой среде получить не удалось: поиск и API Unsplash были недоступны, работал только
CDN с изображениями. Перед публикацией откройте снимок по ссылке, найдите его страницу на Unsplash
и при желании добавьте имя фотографа — это хороший тон, хотя лицензия этого не требует.
